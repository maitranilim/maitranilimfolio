brickflux.vercel.app

01 Interactive game · Canvas 2D

Brickflux

Order vs Chaos in the browser. A Builder and a Breaker bounce around a brick grid and you set the rules: speed, round length, chaos.

  • Seeded challenge links replay the same grid with the same settings for anyone who opens them.
  • Sub-stepped physics so fast balls never tunnel through bricks.
  • Keyboard and screen-reader friendly, with Playwright tests in CI on every pull request.

02 Full-stack product · React + TypeScript

Aural

Tells you where a song actually sits: genre, subgenre, and microgenre, instead of stopping at “Dance”. Search a title or hold up your phone.

  • Shazam-style mic recognition via AudD, with a speech-to-text fallback when nothing matches.
  • Three levels that must all differ, plus a confidence score and an honest note when it is only a rough guess.
  • All provider calls run server-side, so API keys never reach the browser.

  • TypeScript

matchbox-simulator.vercel.app

03 3D physics sandbox · Three.js + Rapier

Matchbox Simulator

A small fire lab. Strike a match, open the cupboard, and watch how everyday objects react to an open flame.

  • Rigid-body physics with real masses in grams and real gravity, so objects collide instead of passing through.
  • Every item behaves differently: steel wool gains weight as it burns, flour dust explodes, water on hot oil erupts.
  • A safe way to see why you never put water on an oil fire.
